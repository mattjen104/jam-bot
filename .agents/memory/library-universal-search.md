---
name: Library universal search
description: Search placement and how selecting a result changes the Library grouping context.
---

Library search is universal across songs, albums, and artists and appears before Group by.

**Why:** Search should express what the listener is looking for, while Group by describes the resulting context. A song-only search forced users into Songs even when they intended to find an artist or album.

**How to apply:** Show typed matches with their entity type. Selecting a song switches to Songs, an album to Albums, and an artist to Artists with that artist focused. Free-text album searches filter the active album workflow.
