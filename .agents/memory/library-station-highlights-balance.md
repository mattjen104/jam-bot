---
name: Library station Highlights balance
description: Defines the boundary between concise station recommendations and full-catalog browsing.
---

Library station Highlights should answer “what should I try?” with two sections: For You and balanced editorial discoveries. When a listener has entered a ZIP, their nearest eligible Bro Zone station is pinned first in For You; the remaining personal matches retain their existing crossing order with duplicates removed. Specialist, era, and mission-led picks share one discovery group rather than separate shelves. All stations and the remote remain the complete browsing surface.

Every Highlights station gets one concise, station-specific curation sentence. It appears before personal crossing evidence; crossings are the quieter secondary line.

**Why:** Separate local, specialist, era, and mission shelves made Highlights behave like a second catalog and pushed deliberate browsing too far down the page. Local relevance should improve the recommendation order without creating another section. Raw location/category metadata does not explain why a station is worth trying, while leading with crossing counts hides the editorial recommendation.

**How to apply:** Keep both detailed and remote layouts on the same shared composition and sentence hierarchy. Pin only the nearest Bro Zone station when a ZIP-derived location exists, then preserve the crossing-ranked sequence. Keep Bro Zones available in All stations filters. Ground explicit copy in reviewed station evidence; use an honest taxonomy-based fallback so no Highlights card is blank. New categories belong in the balanced mix or All stations filters, not new Highlights sections.
